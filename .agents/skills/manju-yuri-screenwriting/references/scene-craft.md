# 场景、关系与对白

## 人物靠选择互相认识

为每位主要人物找三件可以被演出来的事。她此刻想办什么。她遇到麻烦先用哪种办法。哪一种好意反而会冒犯她。把外形、性格形容词和生平放回剧情需要的位置。「冷淡」可以是她先让客人选座再问来意。「善解人意」也可以让她一直替别人回答，直到对方要求自己说。

区分三层信息。**她自己感觉到什么，另一人有理由知道什么，观众能看出什么。** 有人只意识到自己还想听对方说几句，另一人先把这当成工作默契，观众则发现她从来没为别人改过交班时间。下一场可改变其中任何一层。例如让一人发现先前的偏心，或让观众第一次看出另一人也在等。双方的变化不必同时发生。

| 要写的变化 | 让它在场上成立 |
| --- | --- |
| 从留意到想多了解 | 她看见对方如何对待一件两人都在场的事，之后换了原本的做法。比如擅长修琴的人看见对方把一段总被跳过的空拍练了十遍，后来愿意替她留住那段静默。 |
| 从职责内的照顾到偏爱 | 先让观众看懂职责到哪儿结束，再让她做出职责外、对方可以拒绝的选择。对方理解其中多少，可以分开写。 |
| 从默契到错拍 | 给两人各自合理的判断。有人接话是在帮忙，有人听成被替自己作主。让双方在当前任务里承担误读的后果，并有机会决定如何处理。 |
| 从亲近到明确的边界 | 让边界改变安排。被拒绝的人可以停下、改条件或先回去办自己的事。若后来更亲密，写出她们如何回应彼此的新选择。 |
| 从含蓄到直说 | 先有值得承担的后果。直说可以只谈一件具体的事，比如「你可以下班后来等我」，也可以明确说喜欢。语气与后果由故事和创作者的尺度决定。 |

人物可以在意别人怎么看待自己的关系，也可以只烦眼前一件生活小事。处理身份、家人或工作权力差时，写清压力从何而来、角色能决定什么、愿意让谁知道。情感指向和亲密尺度分开控制。角色明确喜欢女性，仍然可以把动作和台词写得很轻。即使故事止于单向心动，也让另一人拥有自己的目标和判断。

## 搭起一场再找句子

1. **从仍来得及改变的时刻进场。** 找正在发生的一件事，再用行动中的小反常或信息差提供观看理由。比如归还号码牌时，早走的人偏偏留到最后。前史从当下选择需要它的地方出现。
2. **给观众一个落脚点。** 想清这一场我们先跟谁、看见谁的犹豫、要不要早于另一人知道原因。可以让观众先看见偏心，也可以等另一人发现时一起明白。误会的两种解读都要能从场上找到依据。
3. **让后一步改变前一步。** 一人提出、另一人接、拒绝、改条件或做出意外动作。接下来的行为要受这次回答影响。遇到低强度的戏，转折可以是她第一次觉得自己的爱好被认真对待，也可以只是她终于停止替对方圆场。
4. **停在观众能接住的地方。** 本场的变化已经落地就可以出去。用响应、完成的事、变了用法的物件、被接住的一句话或一次真的告别收束。重复的动作只有在处境或意思变了时才值得再写。

粗排时可在内部写一行「入场时她们各要什么 → 哪步让旧办法走不通 → 谁作了什么选择 → 出场时有什么变化」。正式稿把这行还原成动作、台词、反应和声音。

## 台词让人开口之后还能做事

- 写之前给两个人各一句只有作者知道的议程。「我想确认她会不会来。」「我不想被当成需要照顾的人。」再给眼前的事务一个真实问题。她们可以好好回答、故意只答一半、把问题还回去，也可以用行动回答。
- 用身份和习惯区分声音。一个人面对麻烦会先报能办到的事，另一个会先确认谁来负责。她们对别人和对彼此的称呼也会不同。句长、语气和停顿跟着处境变，偶尔说出和平常不一样的话要有场上依据。
- 两人都知道的背景优先变成做法。例如住过同一间房的人顺手知道哪扇门得往上提。需要让观众知道分歧时，让角色纠正眼下仍有影响的版本。眼前的事务说清楚，感情可以留给选择和反应。
- 静默和声音也能承担行动。写清她在等回答、等机器停下、听见了谁的声音，或者选择把正播放的录音按停。足以改变剧情的画外台词标明来源。角色听得见什么和观众听得见什么要分清。

### 群像轻喜，让她们同时忙自己的事

同一场里可以有人想快点结束，有人还在想怎么救场，有人只顾把声响弄小一点。让她们从自己手头的事切入。两三个人可以先听出同一句话的不同意思，也可以没人及时回应。有人插话后会有具体后果，例如拿错了纸、答应了别人还没说完的事，或者把原先只有两人知道的习惯露给了第三个人。熟人可以直接省掉彼此已知的部分。读到对话像问卷时，先换她们在场上的行动，再找会脱口而出的话。

有趣的一拍通常能讲得出起因和落点。例如某人一向按规矩来，这一次她很认真地替另一个人钻空子，对方回头也给她留了一个能接的台阶。想写热闹的修罗场时，让争的东西具体到位置、资格、物品或时间，并给当事人改变安排的机会。给场面留一点余裕，人物之间可以有没接上的话、听见后装没听见的反应，或说到一半改去做另一件事。

### 让心声和现实各演一半

动画或漫剧需要吐槽时，心声可用来交代女主以为自己掌握的办法。下一拍用现场把它推翻，或者让她发现自己只猜对了一半。Q 版小剧场也可以表现她的错误预演。挑最有反差的一次用，给观众时间看她实际怎么收拾。对角色的真实喜欢或不安，优先让观众从具体反应发现，再决定是否需要一句直说。

例如校园午间广播，女主主动报名念菜单，想把自己的名字说一次就收工。

> △ 小克把卷起来的稿角压平。话筒灯亮了。
>
> DeepSeek（心声）：名字念一遍。剩下全是菜，菜又不看我。
>
> △ 哈基米提前碰到了喝彩音效。小龙姐忙着往下拉音量。
>
> 小龙姐：小点儿，隔壁午睡呢。
>
> DeepSeek：今天的菜是 DeepSeek。
>
> △ 哈基米的手还搭在喝彩键上。DeepSeek 把自己揉皱的那一角按平，没把话筒让出去。
>
> DeepSeek：菜是土豆烧鸡。DeepSeek 是念菜的。

去掉心声，这场仍能看懂她想播完、播错了，又自己把话说回来。加上心声能让观众先知道她为自己订了多么简单的办法。角色是否需要旁白、要多夸张，跟着用户要的类型和节奏走。

### 同一个问题的两种落法

夜市结束，负责摊位安排的应宁知道苏麦怕自己再被排到风口。较空的一拍是应宁说「我一直都在照顾你的感受」，苏麦脸红。改从当场必须作的选择开始。

> △ 应宁收起桌面上的摊位牌，空出中间一格。
>
> 应宁：下周我给你留里面？
>
> 苏麦：外边。风一起来，烤栗子的味才散得开。
>
> △ 应宁拿起刚放进盒里的最外一张牌。
>
> 应宁：你上回冻得连零钱都数不动。
>
> 苏麦：那你早点来。你不怕冷。
>
> △ 应宁把牌递给她。
>
> 应宁：几点生火？

苏麦先纠正对方对她的判断，再用自己的办法发出邀请。应宁问的是生火时间，接受的是一段她原本没有理由参与的早晨。若这场需要更明确的恋爱指向，应在前一拍给观众看见她们各自对其他人的分寸，或让后续一次主动赴约承担结果。

已有关系也可以从一件具体的小事写起。明穗习惯替恋人任夏掩上录音间的门。任夏自己把门打开，说「我还在等小郭。她改了两句，得当面念给我。」明穗原本要替她隔开走廊的声音，听完把椅子挪开，改问「那我下班来接你？」改变的是任夏可以决定哪一刻关门，以及明穗怎样表达她愿意等。
