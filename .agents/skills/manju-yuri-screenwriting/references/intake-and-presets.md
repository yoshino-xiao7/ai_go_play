# 新故事怎么聊，预设怎么选

## 首轮先听用户想看什么

这是新故事、空白灵感和方向探索的入口。先读已给出的素材，三项里缺哪项就问哪项。每项都接受大概范围，也接受「没想好」或「你定」。已有明确续写、局部修改、诊断或直接写的指示时，承接已有设定和指示推进。

全空时可以这样问。

> 1. 你大概想看什么故事？给我一个场景、两个人的关系，或者你最想看到的一个瞬间都行。
> 2. 你想做成一集完整故事，还是几集连起来？有大概的集数吗？
> 3. 每集大约多长？比如 60–90 秒、2–3 分钟，或者你已经有一个时长目标。
>
> 想从预设起步也行。比如「日常慢热，错班交接」「职业轻喜，两人临时组队」或「旧搭档重逢，偏酸但收得住」。你也可以只说「第二个，4 集，每集 90 秒」。

题材或尺度已经定下就带进问题。例如「你已经定了两位旧同事、6 集、不表白。单集大概多长？」用户给了一张图或一段视频时，可先复述一个确实可见或可听、能生出戏的细节，再让用户决定从什么关系切入。用户说「想甜一点」「不喜欢工业糖精」等口味判断时，等有具体选项再校准，无需首轮把所有口味分开调查。

## 根据回答给两三套可选方案

方案从用户提供的那一点出发。每套写清主角正在争取什么、什么变化会逼她换办法、为什么这些人会被这件事触动、关系能写到哪一步，以及这个故事适合的集数和时长。配一个短动作或一句对白，让用户能判断实际气质。对方可以选一套、指定换掉其中一项，或让你定。

用户已经从开场预设里选了一个方向时，优先深化这条。只有还存在足以改变故事的选择，才给一两个变体。若用户要求你直接定，说明所选方向和体量后继续写。

两套方案若换了行业和人名还能共用同一份分集，说明差异太薄。至少换掉一项能改变剧情因果的东西，比如关系原有的边界、反复发生的具体任务、谁承担决定的后果、或结尾需要兑现的选择。用户偏好已很具体时，可以保留唯一的故事前提，只给真正影响体验的两个变体，例如「从两人重逢写起」和「从她们已经一起工作一周写起」。说清哪套最接近已给口味及其取舍。

### 用来生故事的预设

下列预设示范不同的推进方式。取其结构，具体人物和事件按用户素材另写。单集可以直接抓一个关键决定，多集需要每次见面都有新的条件或后果。

| 预设 | 戏为什么会接着发生 | 能看见的一个瞬间 |
| --- | --- | --- |
| 群像日常 · 总有人先到 | 几位邻居每周都来社区阅读室坐会儿。有人认真看书，有人只是喜欢在这里等雨小一点。每集可以从谁先到、谁缺席、谁熟悉了这里的习惯里长出一个小笑点或发现。 | 一个总说借把伞就走的人，开始提醒新来的把伞尖转过去，省得水滴到大家最常坐的位置。 |
| 视角慢热 · 两个人记住的不同 | 两个人在同一段空闲里渐渐熟悉。对一人是平常的顺路，对另一人是一天里最期待的时刻。每次换视角，只补对方实际留意或决定的一件事。 | 说自己只是顺路的人走到路口，才发现前面新开了一家更近的店。她还是拐进平时等对方的那条街。 |
| 关系轻喜 · 开心归开心，意思各算各的 | 她们对同一次相处有两种解释。一人喜欢随时都能改约的自在，另一人已经开始把它当成约会。每次约或不约都给双方选择的机会，场面在说清一小步后继续。 | 本来只是把活动办得很开心。一人给大家发下次的报名链接，另一人只问她周末有没有空。 |
| 校园团宠 · 愿望实现过头了 | 新人只想让同学认识自己，第一件主动做的事却让她被公开关注。有人替她挡人，有人想和她比一次，有人已经约她一起去做事。她要逐渐决定自己想收下哪种关照、愿意怎样回给别人。 | 她提前背熟了值日广播的最后一句。广播灯还没灭，她对躲在门口的朋友说「你别笑」。全校只记住了这三个字。 |
| 日常慢热 · 错班接力 | 两人轮流值同一个岗位，各有办法。前几次只能靠交接事项熟悉对方，后来有人自愿调班来当面处理一个问题。轮到谁负责、能不能按旧规程办，每回都变。 | 她接晚班时总是踩点切到循环广播。某天她把切换键晚按了十秒，听完上一班那句每次都被截断的「明天见」。 |
| 职业轻喜 · 各有一套 | 两人要一起完成一场社区展演。一个想保证节目准点，另一个想给第一次登台的人留下重来的机会。她们各自擅长的办法轮流奏效，也轮流留下麻烦。关系推进落在何时愿意让对方接手。 | 前面每次彩排都计时的人，听见同伴说「再给她一次」，自己把计时器按停，走上台接住忘词的小演员。 |
| 重逢偏酸 · 同一段旧事有两种讲法 | 两位旧搭档回来收拾曾一起经营的木偶剧场。台板、偶头、演出名牌归还给谁，每一项都需要重新说清当年是谁留下、谁拿走、谁替谁作了主。最后落在她们是否愿意再把一个木偶抬上台。 | 一个偶头两个人都伸手去拿。她们各自带来了另一半零件，一拼发现谁都没有扔掉。 |
| 轻悬疑 · 听见了还要不要说 | 一位修老录音机的女人帮另一位恢复一段断掉的留言。一段声音能解决一个小问题，也可能把本来只说给某个人的话交给另一个人。查到什么和是否转述由两人分别承担。 | 磁带里叫的是她小时候的名字。修理师按下暂停，把耳机转向当事人，让她自己决定接下来要不要听。 |
| 已是恋人 · 照顾的方式要重谈 | 一人习惯替对方安排，一人想自己决定。轮到工作、家人来访或共用空间时，两人各自把一次好意用错地方，再学会问具体需求。多集靠不同的边界与约定推进。 | 她把备用钥匙放回桌上。对方回家后照样敲门，等她亲自开。 |
| 短暂相遇 · 同一条路走两次 | 两人只有一个固定期限能同行。每次见面都得在完成眼前的事和为对方多留一点时间之间选择，直至最后一次能坦白提出延续或告别。 | 末班渡船的汽笛响了。一人把船票退回窗口，等对方打完那通电话。对方挂断以后，先给她指了一家还开着的旅馆，再问她要不要一起吃饭。 |

### 体量也是可以选的预设

用户明确给了集数和时长时，在这项限制内设计。需要给建议时，将长度和实际能写出的变化绑在一起。以下为方便讨论的起点。

| 体量 | 通常能装下什么 |
| --- | --- |
| 1 集 × 60–90 秒 | 一件眼下的小事，两次有因果的行动和一次可见的关系变化。适合用来试对白和人物化学反应。 |
| 3–4 集 × 90 秒–2 分钟 | 一个反复见面的理由，几个不同的相处节点，加一次有依据的兑现。适合关系向前一小步。 |
| 6–8 集 × 2–3 分钟 | 一条能反复改变两人责任或处境的事件线。可以写一次相互看见、一次真实分歧和一次选择之后的相处。 |

集数变少时优先合并作用相同的见面。单集变短时，把最该让人看见的那个决定留在当集，把它之前的背景交给一个动作或一句当场说得出口的话。集数变多时补新的因果阶段，例如共同办事的规则改了、有人必须承担先前决定的后果、两人第一次处理不同方向的生活选择。

### 用一个场面校准口味

用户点名参考作品时，可以让她选具体喜欢的部分。用《轻音少女》的群像日常和《恋人不行》的双人判断差可以放在同一个故事里。群体戏占多少、好感能读到多清楚、对白要多快，分别商量。用 [同一场合的三种写法](japanese-yuri-craft.md#同一个中文场合的三种写法) 作参照。

用户说先前的稿「不对味」或很难描述偏好时，拿她们在这部戏里确实会遇到的一刻，写两个各几行的版本。一次只比较一个影响体验的选择。比如旧搭档取回练习本，偏轻喜可以让她翻到两人吵架时画的歪谱子，先问「你那天也没看懂吧？」偏轻酸可以让她看见自己夹在里面、原以为已经扔掉的车票，再问「这个我能拿走吗？」让用户指出喜欢哪个回应、哪句像她们说的话。

把回答变成后续能执行的约定。比如「更轻酸」可以落成「保留旧默契，结尾各自离开，给对方一句现在能说出口的话」。用户确认的口味适用于当前故事，新的故事从新的材料判断。

## 一次从零到可写的对话

用户说「想写两个在小镇渡口工作的人，有点遗憾但别太苦。」已知地点和余味，集数和时长还空。先问计划做几集、每集多长，顺带给用户选择「第一次熟起来」或「以前一起值班，最近才重新见面」。如果用户答「六集，每集两分钟，她们以前一起值班」，可给下面这种选项。

- **末班交接。** 一人要把末班接驳改到更早，一人坚持旧时间还有人赶得上。前几集分别处理坐错站、临时多等的成本和谁替谁承担投诉。结尾时刻表照常换，其中一人按自己时间来码头见对方。偏现实，一次分歧需要两人当面说清。
- **失物簿。** 停运前要归还柜里的失物，两人对归属有不同判断。每件真有人回来认领的东西都带出当年一条漏写的信息。最后一本没被认领的航线笔记由原主人拿走，两人另外约一趟船。更安静，旧事通过物件和当事人的处理逐步出现。

如果用户选「失物簿，但把停运改成渡口搬迁」，确认这个取舍后按所选方向推进，把「撤离旧站」和「新站还有没有见面的理由」写进剧本的因果。遇到素材明确、只要一场的请求，直接用那一场能发生的事写出正文即可。
