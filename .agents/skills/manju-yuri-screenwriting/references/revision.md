# 剧本诊断与修订

## 先读用户要改到哪里

- **诊断**给出最影响观感的两三处。每处用集场号和原句或动作定位，说明观众现在容易怎样理解、问题从哪一拍开始、可以改哪个决定或回应。需要时附几行替换示范。
- **重写或精修**直接交修改后的稿件。先保住用户要求保留的台词、故事事实、谁知道什么和后续依赖的结果。其余改动跟着本轮目标走。改变结果会影响下集时，指出具体要改动的集场。
- **规范格式**把原有场头、叙述和台词放到合适位置，保留作者措辞和顺序。来源有歧义时标出对应位置。需要改内容则按用户的改写范围处理。

「太 AI」「像工业糖精」「没感觉」先当作读稿反馈。引用具体位置，确定要改的是故事走法、关系温度、信息出现的时机还是台词表面。用户明确说「保留这段尴尬的聊天」时，把尴尬作为表演目标。

## 从因果改到措辞

| 读稿反应 | 找证据 | 下刀的位置 |
| --- | --- | --- |
| 有设定，戏一直没开始 | 看第一场前几行，观众能说出她现在想办什么吗？ | 从一次已经开始的行动写起。把认识过程压到人物能自然纠正或提醒对方的那一拍。 |
| 一眼能猜到后面每一集 | 对照两集，各自的行动、对方的回应和结果能否互换？ | 先换掉一个人物可选的办法，或让上次选择带来新的后果。若重复是仪式，保留相同动作，让它每次的意思变化。 |
| 关系一下子跳了两格 | 找第一个能支撑关键选择的观察或代价。 | 给角色一个能看见对方怎样办事的机会，再让她在后面主动选择。短时长可以把观察和回应放在同一场。 |
| 只看出客气或友情 | 找哪一处行为越过职责或习惯，另一人对此作了什么决定。 | 加一个她本可以照旧却改了做法的瞬间。把同样的照顾交给任何人都行时，补此人特有的记忆、愿望或边界。按用户要求控制关系说到多明白。 |
| 太甜或太苦 | 看有多少人在不断验证同一个情绪，高潮的代价从哪儿来。 | 保留最有依据的一次回应。可以用琐事打断甜度，让一句拒绝被尊重，或让人物保住生活中另一件在乎的事。 |
| 两个人都像在写文案 | 隐去人名读一遍，标出解释已知背景、工整对仗、突然总结主题的句子。 | 找她此刻要办的事和最难开口的那部分。用她习惯的办法把事情问清楚，另一个人按自己的目的答。口头禅只在角色确实会说时保留。 |
| 剧本够短，演出来却挤 | 找需要真的做完的动作，以及说完后必须留给对方的反应。 | 先合并同义验证、问候和重复收尾。动作、回应和前因保住。若场数或目标时长仍冲突，把代价和取舍说明白。 |

## 三遍针对性检查

1. **遮掉说明看因果。** 暂时拿走旁白、心声和写给作者的解释。检查剧中仍有足够的动作或话语，能让观众理解决定是怎么来的。用户要求的旁白可保留其语气和独立信息。
2. **把名字遮掉读对白。** 对重要交锋逐句问「她在争取什么」「对方听完还能怎么做」。同一策略反复时留最自然的一次。两人互换也成立时，改她们解决问题的办法，再改措辞。需要道歉、拒绝或确认时，直说通常更好演。
3. **顺着出场状态往后看。** 核对谁在场、谁听见、物件在谁手里、答应了什么、到哪一集才能揭露。按角色语速试读，加上动作和停顿，再核对分场时间。写约数。场中有等候、唱段或要读的文字时留出相应时间。

用户同时给了喜欢的整季样本和不喜欢的对白片段时，分开验证。用集纲检查「主角本集做的事为什么到了下集还有后果」。用正文检查「遮掉心声能否看懂事情，放回去是否多了一层只有她才会有的预判或笑点」。群戏重点查有没有连续的问一句答一句。拿掉一处礼貌接话，把其中一人的注意力放回她正在忙的事，再听这一段能否像熟人之间自然发生。

## 把一次改动写到场里

现稿的主要选择是夜市后要不要把摊位续到原处。用户说「苏麦好像只负责被照顾，把她写得更有主见。结尾仍然去外侧摊，保留『你不怕冷。』」

定位到应宁直接把外侧摊位牌交给苏麦，苏麦只说好。改时让应宁先给内侧。苏麦有自己的理由选外侧，随后借「你不怕冷。」提出让应宁早些来。仍由应宁决定来不来，下一场照常从外侧摊开始。改的是选摊位的人和她说出邀约的时机。可对照 [场景示例](scene-craft.md#同一个问题的两种落法)。
