# ai-go-play 画布控制

本技能负责项目操作。提示词写作和动画制作方法分别读取套件中的 H3 官方提示词、H3 提示词增强、maimai-tangtang 收录技能；保留各项独立规则，不在这里改写或混合。

## 定位服务和项目

1. 沿用用户指定的服务地址、项目和操作范围；未指定项目时先列出并定位目标。
2. 读取运行服务的 `/api/health`、`/openapi.json` 和当前画布，以运行版本 schema 为准。
3. 项目名为 ai-go-play，现有 CLI 入口仍为 `manju`。通过 `--help` 查询子命令，不依赖历史会话的临时脚本、端口、项目号或资料库目录。
4. 有合适的原生命令时使用 CLI；修改结构化文档也可直接调用 API。用户要求记录只留画布时，在内存组织请求，不另建提示词或记录文件。

Windows 一键安装将运行环境放在项目 `.venv`。`manju` 不在 PATH 时，从项目根目录使用 `.venv/Scripts/python.exe -m manju` 或 `.venv/Scripts/manju.exe`；独立安装本技能不会安装画布服务或模型。

修改画布、分组或项目时读 [控制接口](references/control-api.md)。

## 保存和修改

- 先读最新文档，按稳定节点 ID 合并本次变更，保留范围外内容和用户修改。
- `PUT canvas` 是完整文档写入；画布、production、timeline 共用项目 `revision`。
- 独立请求使用新的 `request_id`；重放同一请求保留原 ID。遇到 `409 revision_conflict`，重新读取、合并并重新提交，不用旧副本覆盖。
- 尊重节点和轨道锁定；处理分组时检查子节点坐标，删除节点后清理关联线。
- 普通说明用文字卡；逐镜计划用原生 production 分镜；多轨剪辑用 timeline。计划标为草稿，不填不存在的素材或任务 ID。

## 固定素材和参考

- 导入后使用响应的 `imported_version_id`。上传并关联素材不等于已建立画布卡片。
- 生成输入绑定固定版本及参考顺序；真正输入使用参考边，来源研究或合成关系使用关系边。
- 已通过素材需要复用时，使用固定素材卡，避免自动编排把原生成卡再次执行。
- 候选输出与用户采用分别记录；首个结果显示在空卡上，不代表已经通过审查。

导入、参考连线、单卡生成或外部工具回导时读 [素材和生成](references/assets-and-generation.md)。

## 提交与跟踪

1. 先把完整实际请求草稿保存到目标媒体卡的 `data.generation`，包括提示词、工作流、参数、固定输入、输入顺序和结果策略。
2. 按实际工作流检查就绪状态。自定义工作流验证、内置引擎状态和画布运行预检用途不同，不能互相冒充。
3. 用 `/api/comfy` 查看真实后端与队列。已有其他 GPU 工作时等待，不用全局中断或停服务抢占。
4. 单卡提交带真实 `project_id`、`source_node_id` 和 `result_policy: review`；只提交用户授权范围。
5. 使用依赖图执行前先 `canvas-run plan`，检查执行节点、祖先依赖和缓存，再按对应修订提交。`downstream` 会纳入必需上游。
6. HTTP 接受不等于生成完成。跟踪原生任务到终态，回读实际请求、工作流快照、参数和输出版本。
7. 检查实际媒体并记录检查范围、采用或拒绝结论；拒绝后解除采用绑定，保留原任务与候选，不自动续做下一镜。
8. 取消只针对授权任务 ID。普通取消不打断运行；需要停止本任务的运行部分时再用 `interrupt_running`，不停止无关任务。

## 回导外部结果

用户选择 Codex 内置绘图等画布外工具时，用其真实入口生成，再导入实际原件与固定版本。
在卡片备注或关联文字卡保存真实工具、完整实际提示词、输入职责、输入输出版本及检查结果。
不为外部工具伪造本地模型、工作流快照或 `generation_id`；关系连线不代表图片已被生成器读取。

## 编排、清理和交付

- 在原生分镜或时间线绑定真实来源卡及固定版本，明确区分候选、当前采用和用户确认。
- 实际合成使用原生 production/timeline 渲染入口，跟踪输出并核对素材、入出点和采用版本。
- 清理卡片、清空编排、删除资产是不同操作。按用户范围处理，保留仍在使用的任务及范围外内容。
- 重新开始时只保留用户指定的原稿、主体、原句和底稿，不让旧试镜自动成为新计划输入。
- 需要可编辑工程时导出 `.manju`，检查必要素材和制作记录是否保留。

原生分镜、时间线和导出操作读 [分镜和时间线](references/production-and-timeline.md)。
