# H3 Image 静帧提示词与画布接入

## 选模式和固定素材

- **文生图**从文字描述构建画面。**图像编辑**以第一张图为底图，可借用其他图片里的指定信息。**参考生图**用于把素材的可见特征重新组合成新画面。官方使用同一个图像模型，带参考图的任务归在编辑路径。Manju 为参考生图保留了独立画布入口。
- 检查每张输入图的实际内容和固定版本，按提交顺序绑定 `<Picture 1>`、`<Picture 2>`。在画布里可用 `@` 引用，提交后查任务中的编号和映射。三视图是同一张图时，用正面、侧面、背面来定位其中的视图。

## 写成可以直接提交的提示词

- **文生图**用自然的英文画面描述确定主体、地点、画幅、视角、构图、前后景、光线和材质。把抽象意图落实为可见细节。镜头首帧应表现动作发生前一刻，并让人物站位、手与道具的接触、视线和空间关系读得清楚。需要标题、对话框或图表时，写齐可见的文字和数据，逐项核对数量和版式。
- **编辑和参考生图**交付一段连续英文，按素材定义、目标与保留关系、变化或新增细节推进。先用 `<Picture n>` 定位可见来源，涉及多个需要分别跟踪的对象时，可定义 `<Subject n>`。再说明目标画面、哪部分完整保留、哪部分变化、从哪张图借用何种属性。最后写清新增或变化部分的造型、位置、比例、光影及接触关系。只给需要继续使用的来源对象编号。
- 用目标画面的最终状态来写编辑。完整保留的对象按官方格式单独写 `<Subject N> is fully preserved.`，后续只用编号来定位。部分保留时写明保留的属性和变化的属性。仅借用颜色、纹理等属性时，单独定义该属性和接收它的对象。来源仅作宽松的风格参考时，说明借用的特征和允许变化的部分。
- 显示在画面上的文字保留用户要求的语言和原句。需要匹配参考色、纹理或样式时，指出来源图和应用部位。画幅作为独立生成设置记录，并保留用户明确给出的宽高或比例。

## 复核与交付

- 若工作流开启提示词增强，给增强节点的是用户意图和正确编号的参考图。排查结果时同时核对输入指令、增强输出、实际上传的图片顺序、工作流版本和固定种子。用户只要提示词时，交付可复制正文，按需附画幅。
