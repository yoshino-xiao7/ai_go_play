# Manju 图生视频与交接

用于从分镜写本地 MiniMax H3 的图生视频描述，或在用户点名时把通过复核的分镜写入 Manju。先查目标项目和实际工作流设置。写方案时可以采用已声明的默认值，素材是否可用以固定版本和画面核对结果为准。

## 选输入模式

| 镜头需要 | Manju 绑定 |
| --- | --- |
| 从一张已经构图的镜头首帧开始 | `video_mode: frames`，使用实际图片版本的 `first_frame`。提示词直接从图上的人物和物件位置起写。 |
| 首尾状态都必须贴住 | 同为 `frames`，按需加一张实际的 `last_frame`。两张图的轴线、人物和道具位置必须能由镜内动作接起来。 |
| 要同时输入构图帧和分开的角色、场景或道具参考 | 选 `reference`，所有输入用 `reference` 角色，按实际图片顺序使用 `<Picture N>`。需要引用时优先用 Manju 的 `@` 素材提及，让系统编译编号。 |

用立绘确认人物，用镜头构图图确认动作起点。检查手是否够得到物件、身体是否有变换重心的空间、关键动作是否留在取景内。首帧已经发生的动作从其后果写起。全参考时注明每份素材的职责与优先级，例如构图图定机位、立绘只定身份、音频只定音色。按任务真实挂载顺序写标签。待补素材用 `KF-...` 或 `PLAN-...` 标明。

本地 H3 请求时长为 4–15 秒的整数，24 fps。分镜另记实际剪辑时长。短镜可以按 4 秒生成并保留末态，再取需要的片段。长镜在动作完成或换景别时拆分。H3 实际输出按 `17k+5` 帧取不短于请求时长的帧数，例 4 秒请求得到约 4.46 秒，剪辑时根据素材实长定入点。全参考最多 9 张图片、3 段视频、3 段音频且合计至多 12 项，参考视频和音频单项 2–15 秒、各类合计至多 15 秒。确需改用其他生成器时先按其能力重新检查模式、时长和参考顺序。

## 先排表演，再写提示词

- 从这一拍要观众看到的变化倒推机位、起势和切出。礼堂全景交代人群和地点可以只用一秒。要看出紧张、试探或惊讶，就切到能读出手、身体重心或视线的景别，让声音跨镜。
- 写动作的原因、蓄力、方向、接触和反应。比如被点名后愣一拍，身体前倾、手掌压扶手，臀部离座，肩膀和鲸尾随侧身转入通道，脚落稳再切。用这类完整动作检验模型能否演动戏。人物只需低声自语时，用攥裙、短促吸气和半句话停顿表现紧张，旁人的一来一回可以衬出主角的拘谨。
- 每段围绕一件能看明白的事，允许有前后相承的动作和反应。群像可让几组学生各做自己的事，错开节奏，把重要互动放到可读的景别。切分放在反应、景别或视点真的改变的地方。给运镜明确理由，只有看不清先后的表演才需要用秒段排顺序。
- 保留会影响这一拍的身份、道具状态、空间方向和声音。避开泛化的逐像素锁定与群体静止要求。若输出只有嘴和眼睛在动，先回看首帧起势、镜头尺度和动作链，再决定重写提示词、换参考或换机位。

首帧或首尾帧的单镜可直接用中文描述。按 Drama Skills 的 H3 结构写时，首帧提示词采用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music` 三段。全参考改用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 六段，按本次挂图顺序绑定标签。两种结构的动作段都可用 `[Shot 1]` 标出单镜，无后加音乐时写 `non_diegetic_music: N/A`。三段或六段都作为同一次生成的完整提示词。

沿用项目已经定下的声音方案。使用 H3 原生音画时，开启声音并写清谁开口、原句、停顿、发声窗口和背景声。区分画内对白、广播和心声。参考录音用于音色时用全参考，并给本镜新台词单独指令。字幕、人名条和必须逐字呈现的招牌可后期处理。回看动作和口型，试听对白与底声。转写可以核对文字，口型与表演仍需看成片。

## 排查成片或对比外部工作流

- 从完成的任务回读固定输入、种子、模型快照和实际节点图。外部 ComfyUI 文件从输出倒查已连接的主链，核对上游给定的画幅、时长、输入素材、基模与编码器、LoRA、采样器、调度器和步数。文件名、断开的备选节点及已被连线覆盖的参数只供查阅。先核对本机节点和模型是否齐全。
- 有可比片段时，先固定镜头目标、声音方案、输入、时长和种子。提示词对照只换表演描述。比较本地参数时一次只改一个关键变量。全参考与首帧流程往往同时换条件节点和基模，记录为整条路线对照。分辨率对照主要看细节，动作对照看起势、重心、互动和后续反应。
- 对照版进候选，用相同剪辑长度和前后镜比较。记录实际改善与代价，单次出片只支持本次判断。两版都僵硬时，先换能演出该动作的起始姿态或镜头，再决定是否继续测试。

## 应用户要求写入 Manju

制作文档用稳定镜号追溯场号和来源。用户要求把分镜写进项目时，先用 `manju production inspect --project PROJECT_ID --json` 读取原镜头、共享画布 `revision` 及 `settings`。核对本集是否已有对应镜头，保留其他镜头和设置，按镜号更新或追加，再用 `production apply` 写入。过期修订返回 409，重新读取并合并。素材尚未生成的镜头存为 `draft`，来源卡和固定素材版本字段只填已核对的实际对象。

| 分镜内容 | Manju 字段 |
| --- | --- |
| 镜号与标题、场号与场景 | `title`、`scene`。已有镜头保留 `id`，顺序由镜头数组决定。 |
| 入画人物、发声人、原句 | `characters`、`speaker`、`dialogue`。逐镜只有一组说话人和台词字段。多人或交叠声用合理切镜或多轨交接。 |
| 实际剪辑秒数、素材入点 | `duration`、`trim_start`。生成请求时长另记在提示词文档。 |
| 口型、声音类型、连续性与挂图提示 | `notes`。采用后绑定 `video_version_id`、`audio_version_id`，已有真实来源卡可填 `video_node_id`、`audio_node_id`。 |
