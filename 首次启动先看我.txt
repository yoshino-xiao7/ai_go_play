ai-go-play 首次启动先看我

第一次使用，从这份说明开始。两种方法任选一种；不用先学编程。
本文件与「首次启动先看我.txt」内容相同，发其中一份给 Agent 即可。

开始前

- 在项目仓库页面点击 Code → Download ZIP，下载后解压；也可以用 Git 克隆项目。打开能看到 start.cmd 的文件夹，这就是“项目根目录”。不要只下载这份说明，也不要在压缩包里面直接运行。
- 下面的一键安装方法适用于 Windows 64 位电脑，需要联网。不用提前安装 Python、Node.js 或 FFmpeg，启动脚本会自动准备。
- 只体验画布，不需要显卡模型。要在本机生成图片、视频、配音或口型，需要相应模型及兼容的显卡环境。向导自动安装的是 NVIDIA 版 ComfyUI，需要兼容 CUDA 13 的驱动；其他显卡请查看向导中的“其他显卡与官方说明”。
- 模型可以按需选择。全部模型文件约 174 GiB，此外还需要安装环境和下载缓存的空间。导入会复制文件，下载目录与目标目录同时占空间，请查看页面显示的可用容量。

方法一：把这份文档发给 Agent，帮你安装

把本文件发给你使用的 Agent 工具，同时告诉它项目文件夹的位置。工具需要能访问你的本机文件并运行命令；普通聊天工具只能给出操作建议。

可以直接复制下面这段话发送，把路径换成自己的实际位置：

请按这份《ai-go-play 首次启动先看我》帮我安装并启动项目。
我的项目文件夹是：E:\ai-go-play（请替换成实际位置）。
请先检查电脑环境，再使用项目自带的 start.cmd 启动，并协助我完成 Web 安装向导。
请根据我需要的功能和磁盘空间选择模型。需要我下载模型、登录账号或阅读同意条款时，告诉我具体点哪里。
请保留已有模型、配置和作品。完成后告诉我网页地址、哪些功能已就绪，以及还缺什么。

给 Agent 的执行说明：

1. 确认项目完整，包含 start.cmd、start.ps1、scripts、backend、frontend 和 release。先阅读本文件，再按需查看 README.md。
2. 在项目根目录运行 start.cmd；PowerShell 中可运行 .\start.cmd。无桌面界面时，可运行 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser，并把输出的访问地址告诉用户。
3. 使用项目自带的自动安装流程。检查 Web 进度和报错，不要因为首次下载较慢就重复启动安装。
4. 按下面“方法二”连接 ComfyUI、选择模型目录、导入并校验、安装运行组件。已有 ComfyUI 和模型优先检查复用，不删除用户文件或擅自替换已有显卡运行环境。
5. 网盘模型下载、账号注册登录以及隐私条款和用户手册确认，由用户在对应页面完成；不要索要密码或代替用户勾选同意。
6. 以网页中的完整校验和组件检查结果为准。实际进入画布后再报告启动成功；有缺失项就列明，不将“网页打开了”当作所有 AI 功能都可用。

方法二：自己照着做，Agent 也可以照着执行

第 1 步：双击启动

打开项目根目录，双击 start.cmd。

浏览器会打开准备页面，自动下载环境并安装项目。第一次可能较慢，保持联网，等进度完成。出现下载错误时，查看页面提示并重试。

准备完成后，会进入安装向导。只想先看画布，可以点击“仅使用基础画布”，暂时跳过本地 AI 安装；以后可从画布的“安装向导”入口继续配置。

第 2 步：连接生成引擎

ComfyUI 就是运行本地 AI 模型的程序。

- 已经装过：在“生成引擎”页面选择扫描到的安装目录；没找到就点击文件夹按钮，选择已有目录并“连接目录”。需要时点击“启动 ComfyUI”。
- 没装过：在“还没有 ComfyUI？”下方确认安装位置，点击“下载并安装”。安装完成后启动，等页面显示“引擎已连接”，再点“下一步”。

不清楚目录怎么选，可以保留默认位置；空间不足就换到空闲较多的磁盘。新安装请使用专用的空目录，也可以直接输入尚未创建的完整路径，例如 E:\AI\ComfyUI_windows_portable，程序会创建它。不要直接选磁盘根目录或已有文件的文件夹。

第 3 步：下载并导入模型

在“模型资料库”页面，保留“准备全部模型”，或只勾选想用的功能。

百度网盘：https://pan.baidu.com/s/5nO-pzE6K3be3-t0zkpm1Pw（无需提取码）
夸克网盘：https://pan.quark.cn/s/2ce0688209ca（提取码：BsXE）
两处分类目录相同，任选一个来源，无需重复下载。

1. 点击“打开百度网盘分享”或“打开夸克分享”，在对应官方页面或客户端按提示下载所选模型。大文件请使用网盘客户端。页面会说明所需文件分布在哪些网盘目录；共享模型可能放在其他分类里，也要下载。保留原来的分类目录和文件名；如果下载的是压缩包，先解压。
2. 回到向导，设置“模型存放位置”。可以点“使用默认位置”，也可以选择自己的文件夹。这是模型以后实际使用的位置。
3. 点击“选择下载目录”，选中刚下载的 ai-go-play 文件夹。这里选的是来源文件夹，和上一步的存放位置用途不同。
4. 点击“导入所选模型”，等待完成。导入会复制并检查文件；原下载文件会保留。

如果已有按项目要求整理好的 models 目录，可以直接将它设为“模型存放位置”，到下一步校验，不必重复下载。默认位置在 Windows 用户文件夹里的 ManjuModels。

“扫描夸克目录”只检查夸克在线清单，不代表模型已经下载到电脑。百度下载的文件使用同一份本地清单校验，缺少的文件会在下一步明确列出。

第 4 步：检查文件，补齐运行组件

在“就绪检查”页面按顺序操作：

1. 点击“完整校验”，等待读取并核对模型内容。文件较大时需要一些时间。
2. 如果提示缺失，展开文件列表，按每个文件下方的“网盘位置”找到它，点击“前往百度网盘下载”或“前往夸克下载”补齐，返回上一步导入，再做“完整校验”。
3. 校验通过后，点击“安装 / 连接组件”。程序会为所选功能补齐依赖，包括配音和口型需要的运行环境。
4. 安装完成后点击“检查组件”。由项目启动的空闲 ComfyUI 会按需自动重启；如果 ComfyUI 是你从别处启动的，请到原来的窗口重启它，再回来检查。
5. 等到所选功能显示“组件就绪”，再进入下一步。暂时不用的功能可以返回“模型资料库”取消勾选。

第 5 步：选择身份，进入画布

- 有账号或想注册：选择“亦可账号”，点击“注册 / 登录并连接”，在打开的官方网页完成操作，再回到向导。
- 先体验本地功能：选择“游客进入”，以后也可以连接账号。

打开并阅读《隐私条款》和《用户手册》，由你本人确认后勾选对应选项，完成向导进入画布。

用完怎么退出

1. 在画布顶部点击“退出程序”；项目列表左侧也有同名入口。
2. 点击“保存并退出程序”。如果保存失败，页面会保持打开，先按提示恢复保存。
3. 由工作台启动的 ComfyUI 可勾选一起关闭，释放显存；从别处启动的 ComfyUI 需要到原来的窗口关闭。
4. 如果有生成、合成或安装任务，先等任务完成，或到相应任务面板取消，再退出。
5. 看到“本机服务已关闭”后，关闭浏览器页面即可。项目、素材和账号连接会保留。

“返回项目”只离开当前画布。直接关闭浏览器页面也不会关闭后台服务；要结束程序，请使用“退出程序”。

下次怎么打开

仍然双击根目录的 start.cmd。已经准备好的环境和配置会继续使用。
服务启动后，默认访问地址是 http://127.0.0.1:8765 。这个地址只用于当前电脑；如果使用了自定义端口，以启动输出为准。

卡住了怎么办

- 浏览器没自动打开：服务准备好后，手动访问上面的地址。如果打不开，查看启动报错；首次安装尚未完成时，正式网页还不能访问。
- 双击提示 Windows 脚本宿主不可用：在项目文件夹的地址栏输入 powershell 并回车，再粘贴运行 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1，使用相同的安装流程。
- 下载失败：先确认网络和磁盘空间，再按页面提示重试。不要同时启动多份安装任务。
- 关闭了网页：再次双击 start.cmd，可重新打开正在运行的准备页或工作台。关闭页面不会自动取消后台安装。
- 模型缺失：确认已经下载并解压，选择的是下载文件夹，且文件名没有改动；按缺失列表补齐后再次导入、校验。
- 文件“内容不匹配”：把具体文件名和错误交给 Agent 检查，不要通过改名或跳过校验强行通过。
- 组件安装后仍未就绪：先确认 ComfyUI 已重启，再点“检查组件”；仍失败就把页面上的错误交给 Agent。

需要 Agent 排查时，提供：项目文件夹位置、停在哪一步、页面上的完整错误文字，以及你想使用的功能。不要发送账号密码。

Agent 可查看项目内的 .manju\bootstrap\logs，以及 Windows 的 %LOCALAPPDATA%\Manju\run 中的启动日志；Web 安装任务的错误以页面显示为准。

模型使用各自的许可证，部分限制商业用途、使用地区或托管服务。下载前可在 Web 模型页面打开“模型来源与许可证”，也可直接阅读 release/MODEL-LICENSES.md。
