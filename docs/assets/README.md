# 文档展示素材

`readme-hero*.svg` 为项目标识与创作流程示意。`feature-*.png` 为项目实际 Web 界面的截图，使用独立的《月台来信》演示工程；中英文 README 共用当前中文界面截图。

演示工程中的场景、人物与列车为本项目绘制的 SVG 示例图，视频由示例图构成，声音为合成示例信号。它们用于说明界面操作，不是模型生成质量样本。截图不包含私人作品、账号资料或真实创作工程。

更新时从实际界面截图，保持相同项目、主题和清晰比例。等待字体、媒体与数据加载完成，检查弹窗、轨道及文本是否被遮挡；不得改写截图中的环境检查状态或用未实现界面替代现有功能。界面能力变化时同步对应截图及中英文说明。

这些项目自制的文档图片随仓库源码采用根目录 [MIT 许可证](../../LICENSE)。界面中涉及的第三方名称不构成其对本项目的背书。
