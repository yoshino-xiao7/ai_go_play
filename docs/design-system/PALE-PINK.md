# 淡粉亮色与创作回路

本页记录淡粉配色层，以及以“项目 / 画布起草 → 节点草稿 → 实际提交 → 按轮次结果 → 回填或转视频”为主线的创作交互。原有暗色配色保留为“暗房深色”。

## 配色

- 开关：设置 → 外观与动效。选择保存在本机浏览器（`localStorage`），不写入项目数据。`html[data-theme="studio"]` 仍是结构层，`html[data-palette]` 只负责颜色：`pale-pink` 为默认值，`darkroom` 即原深色。
- 实现：`frontend/src/design/pale-pink.css` 在 `data-palette="pale-pink"` 下重定义语义令牌，[TOKENS.md](TOKENS.md) 中的值保持不变。仍为字面量颜色的界面（见 [STYLE-DEBT.md](STYLE-DEBT.md)）按工作区单独覆盖：项目、画布节点与工具栏、图像/视频生成面板、提示词编辑器、时间线、口型、任务、资产库、工作流、设置和 ComfyUI 面板。
- 颜色角色：
  - 玫瑰色 `#c3487a` 用于强调文字、线条和焦点，在白底上对比度不低于 4.5:1。
  - 淡粉 `#f7b6cd` 是主操作的品牌底色，上面的文字始终使用墨色。
  - 判断画面的区域保留深色（“暗房”）：时间线监视器、口型画面、结果缩略图底，以及“实际提交”中的请求清单。
- React Flow 的 `colorMode` 和点阵背景跟随配色切换（`usePalette`）。
- 检查方法：在隔离实例上逐个工作区扫描大面积深色块、半透明深色叠层，以及对比度低于 3:1 的文字。

## 动效

- “跟随系统”尊重 `prefers-reduced-motion`；“减少动效”会设置 `html[data-motion="off"]`。
- 新增动效只有三类：抽屉滑入、结果从白色中显影、面板上浮。这三类在上述两种情况下都会关闭。状态变化仍然靠文字和颜色表达，不依赖动画。

## 创作回路的语义

- **起草**：项目页“从一句描述开始”和画布空选择时出现的起草条，都只是在目标画布的空位新建图像或视频卡片并填入描述，然后定位到这张卡片，不会提交任何任务。项目页传给画布的意图只使用一次、只对指定项目有效，五分钟后过期。
- **同一份草稿**：常用控件（描述、参考、画幅、方式、工作流）和高级参数都读写节点上的 `data.generation`。“高级”按钮显示与工作流默认值不同的项数。
- **实际提交**：面板里显示的内容与提交时调用的是同一个 `buildRequest()`，包括去向（本机 ComfyUI 或会计费的云端）、按顺序排列的参考版本、不会送出的参数及原因，以及完整 JSON。提交前检查沿用原有限制：工作流可用性、参考数量范围、蒙版、种子、原件是否可读、同名引用。同一节点在服务端一次只运行一轮，有进行中的一轮时不能再提交。不会在客户端排队，也不会把尚未进入引擎的任务显示为已提交。
- **按轮次结果**：内容只读取 `/api/generations` 的真实任务，即 `request` 快照、状态、`outputs` 和 `parent_job_id`。轮次按节点和创建时间排序，并标出与上一轮相比改了哪些参数。客户端不写任务记录。
- **回填**：把某一轮的快照深拷贝到卡片草稿，参考固定到快照中的版本；连线若已指向其他版本，会在这张卡片上排除。H3 视频会恢复快照里的精确帧数 `frame_count`，以及每条参考的 `fit`、`purpose`、`use_audio`、`crop`、`clip_start`、`clip_end`（由 `video_inputs.py` 归一化并冻结）。快照里没有的字段一律清空，不从当前草稿继承；参数也只取自快照。回填会同时清除 `pending_submission` 和 `pending_request_id`，避免沿用旧的提交。“回填再改”沿用服务端实际使用的种子；“同参数换种子”把种子设为 -1。草稿里只增加可选字段 `refill_of` 和 `round_links`，旧项目可以照常读取。
- **采用**：与卡片自带的“采用”使用同一写法（`asset_version_id`、`image_history`、`generation_id`），可以撤销。
- **转视频**：新建一张视频卡片，首帧参考固定为该图像版本（`source: mention`，带来源 `node_id`），不建立连线，因此之后采用其他版本也不会改变首帧。尾帧可选；Turbo 仍然只能用于全参考模式，环境缺少节点时不可选。
- **双向定位**：结果轮次可以定位到节点。参考条目可以跳到来源卡片对应版本所在的轮次；结果被另存到其他节点时，提供“去结果卡片”。
