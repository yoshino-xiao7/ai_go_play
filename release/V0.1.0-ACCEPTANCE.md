## 仍有边界

冷启动仍在同一台实体电脑完成，入口使用无浏览器参数；没有完成第二台电脑、其他 GPU / 驱动、真实账号注册、付费云端生成或跨版本数据库降级验证。备份恢复是同版本完整数据恢复。教程完整下载与安装补录暂停，未包含在本版安装包内。

服务器规则集、默认分支工作流首次接入、实际 Release 下载附件及其 SHA-256，须按[发布手册](../docs/RELEASING.md)继续核实。私有仓库可见性保持不变；本地测试不代表外部未登录用户已经可以下载。

完整日志、测试素材与本机路径留在忽略目录，不纳入发布。待审提交以 PR 的完整 head SHA 为准，新增提交必须重新确认。
