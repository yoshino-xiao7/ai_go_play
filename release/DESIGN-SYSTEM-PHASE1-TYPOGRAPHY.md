# 设计系统阶段 1：时间线与画布状态栏的字号字重（2026-11-19）

本页是带日期的执行记录。规范见 [Design System](../docs/design-system/README.md) 原则 4、[Token 参考](../docs/design-system/TOKENS.md)「文字」和 [样式债务](../docs/design-system/STYLE-DEBT.md) D5。

## 范围

批准范围是迁移方案第 5 项（D5）的试点：只统一时间线和画布状态栏的字号与字重。

- 不改颜色、业务逻辑、画布交互和其他页面，不引入字体依赖，不进入第 6 项。
- 分支 `codex/design-system-phase0`，起点 `5104e24`。只在本地提交，未推送，未合并。

## 盘点（`5104e24` 实测，1440×900 与 1920×1080 结果相同）

| 范围 | 可见文字 | 小于 11px | 中文小于 12px | 被裁剪 |
| --- | --- | --- | --- | --- |
| 时间线（选中片段） | 104 | 72 | 61 | 5（均为省略号截断） |
| 画布状态栏 | 2 | 2（9px） | 2 | 0 |

时间线的字号是在 `timeline.css` 中逐条写的 9 / 10 / 11px，涉及：

- 尺标时间、片段时长、轨道说明、预览说明：9px；
- 片段名、素材名、轨道名、字段标签、检查器分隔标题：10px。

字重只用了 400 / 600，没有无效的中间值。

`timeline.css` 中按钮和输入框的字号声明实际不生效：同一个样式块中更靠后的 `.canvas-workspace button, input, textarea { font: inherit }` 与它们特异性相同，会把它们覆盖。所以按钮实际继承根元素的 12px。本批不改这些声明，记入 D5。

## 结果

| 指标（两种视口相同） | 之前 | 之后 |
| --- | --- | --- |
| 时间线中小于 11px 的文字 | 72 | 0 |
| 时间线中小于 12px 的中文 | 61 | 16（全部是 11px 的数字元数据） |
| 时间线中被裁剪的文字 | 5 | 2 |
| 画布状态栏 | 9px，行高 12px | 12px，行高 16px |

- 时间线：
  - 被裁剪的 2 处都是省略号截断：3 秒片段「03 · 候选 A」在当前比例下宽 52px，另一处是长名称测试用例。没有纵向裁剪。尺标时间不重叠，最小间距 26px。
  - 工具栏、工作区三栏、监视器、播放条、检查器、编辑栏、尺标、轨道行和片段的边界框都不变。素材列表的可见区域少了约 23px，因为底部提示换成了三行；列表本身可以滚动。
- 画布状态栏：187×16px，与工具栏的水平间距为 147px（1440）/ 387px（1920），没有裁剪。在 `canvas-image-fail` 中元素数由 14 变为 15，正常显示。
- 最终 HEAD 对基线：
  - 182 张截图，0 张失败；
  - 非预期的元素变化为 0；
  - 93 张像素一致，其余变化都在时间线内部或画布状态栏。凡是能看到画布的状态（包括叠在画布上的弹窗）都包含状态栏，所以都计入变化。
- `1440-comfy-input-focus` 另有一块像素差异，位于 ComfyUI 状态文字处：基线截到的是「正在连接」，最终截到的是「等待配置」，是服务状态请求返回时机不同。该处元素样式完全相同，属于采集时序，与本批无关。

## 未覆盖与延期

- 窄视口（≤ 1100 / ≤ 900px）没有采集，相应规则没有修改，仍有 8–10px 的文字。
- 只在导出时出现的导出进度区、预览错误、时间线横幅，没有渲染出来。规则已按 Token 修改，但没有截图证据。
- 状态栏的颜色和 3.0:1 对比度保留原值（本批不改颜色）。素材面板展开时状态栏被面板遮挡，修改前后相同，属于原有情况。
- 缩放读数（10px）属于缩放控件；画布节点内文字、其他页面、`Inter`、等宽字体、无效的按钮字号声明，都记入 D5。

- 只在 Windows 的无头 Edge 中验证。
