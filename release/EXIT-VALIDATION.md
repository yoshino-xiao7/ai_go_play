# 退出程序验收

日期：2026-11-14。仅本地更新，未发布。

画布顶部及项目列表侧栏新增“退出程序”。确认后先完成画布保存，再请求本机服务正常退出。保存失败或存在版本冲突时保留画布；有生成、合成、编排、安装、存储迁移或文件传输时，服务端拒绝退出并提示处理未结束任务。

由工作台启动的 ComfyUI 默认勾选一起关闭，关闭前再次检查进程归属及队列；不强制取消任务，不停止外部启动的 ComfyUI。服务停止后显示可关闭浏览器页面的提示，下次仍使用 start.cmd。

## 实测

- 退出专项自动测试 11 项通过：明确确认、同源限制、未托管服务、忙碌状态、并行导出、ComfyUI 归属和队列、退出期间阻止新写入、真实 CLI 服务退出与再次启动后项目保留，以及旧资料库升级不伪造条款确认。
- 关联 CLI / 配置测试通过；退出与首次引导组合测试 24 项通过、1 项因 Windows 符号链接权限跳过。
- 前端 TypeScript 检查和生产构建通过。
- Edge 实测 1440、1024、768、390 像素宽度：按钮可点击，取消后画布保留；模拟保存失败时未发送退出请求；恢复保存后通过真实 API 关闭隔离测试服务，端口释放。
- 正式服务已启用接口；只读打开用户画布的退出弹窗验证通过，未在正式环境提交退出请求。激活前检查没有未结束任务并备份数据库；重启前后指定画布内容一致，ComfyUI 进程保持不变。

首次引导上线前已经存在的资料库，升级后仍可进入工作台，不自动勾选或写入隐私与手册确认。用户主动打开安装引导后，仍按原流程填写并确认；全新资料库继续首次引导。

隔离测试、截图及激活记录位于本机忽略目录 `.qa/exit-application/`。旧版常驻服务需要重启一次才能加载新退出接口，前端会对旧版接口缺失给出明确说明。
