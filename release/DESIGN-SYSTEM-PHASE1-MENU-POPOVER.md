# 设计系统阶段 1：统一菜单与弹层（2026-11-19）

本页是带日期的执行记录。规范见 [Token 参考](../docs/design-system/TOKENS.md#菜单与弹层阶段-1d9)、[迁移方案](../docs/design-system/MIGRATION.md) 第 3 项和 [样式债务](../docs/design-system/STYLE-DEBT.md) D9。

## 范围

批准范围只有迁移方案第 3 项「Menu 与 Popover 统一」：整理菜单和弹层共用的表面、描边、圆角、阴影和状态规则。参照两个组件：

- 菜单参照画布右键菜单：分组、快捷键、危险项；
- 弹层参照视频参数弹层：分段选项、选中态、底部说明。

本批不包括：

- 不改业务逻辑、键盘交互、焦点行为、弹层定位、层级（`z-index`）、遮罩和挂载方式；
- 不涉及 Button / IconButton，也不修正层级。

分支是 `codex/design-system-phase0`，起点 `2c69500`。只在本地提交，未推送，未合并。

## 盘点结论

已渲染的界面里共有 7 种菜单 / 弹层外观。

**两个参照组件和共享弹层组**（参数、选择框、画幅与尺寸、生成参数、参考图选择）：外观已经一致。

- 暖色抬升表面、强描边、14px 圆角；
- 共享阴影 `0 12px 36px #0006, 0 1px 4px #0003`；
- 菜单项 36px 高、8px 圆角。

**另外 5 处各有一套取值：**

| 组件 | 原外观 |
| --- | --- |
| 画布「更多」菜单 `.canvas-more-options` | 冷蓝灰表面，10px 圆角，菜单项 34px、5px 圆角，冷色悬停 |
| 项目卡片菜单 `.dropdown` | 8px 圆角，5px 内边距，自有阴影，菜单项 34px、4px 圆角 |
| 工具栏「新建主体」「添加画框」菜单 `.canvas-frame-options` | 面板表面，白色 12% 描边，12px 圆角，较重阴影；悬停沿用工具栏图标按钮的白色 9% 底色 |
| 画布项目菜单 `.canvas-project-dropdown` | 12px 圆角，自有阴影 `0 16px 40px` |
| 画布节点搜索 `.canvas-node-navigator` | 偏紫的旧色：`#211f28f5` 表面，`#5b5367` 描边，`#403447` 悬停 |

**保留的差异**（不是视觉债务）：

- 各组件的宽度和定位；
- 右键菜单的子菜单、快捷键、分隔线、方向键移动焦点、靠右时向左展开；
- 「更多」菜单的导航箭头；
- 项目菜单的搜索框、行操作和 9px 内边距；
- 除右键菜单外，其余菜单的键盘焦点环；
- 工具栏菜单的居中定位和 3px 项间距。

## 验证方法

- 数据：每次采集都从冻结的黄金数据复制一份新数据，在隔离端口上运行。黄金数据含 5 个项目、合成素材、剧本与时间线。不接触生产素材库，不使用凭据。会写入数据的状态各用独立的数据副本。
- 视口：1920×1080 与 1440×900，无头 Edge，dpr 1，zh-CN。
- 每个单元：
  - 执行 `npm run build`（含 `tsc -b`）；
  - 运行 `node --test tests/governance.test.cjs`，14/14 通过；
  - 在两种视口下采集受影响的状态和至少一个相邻对照状态，逐元素比较计算样式，像素按通道取最大差值，超过 24 计为变化；
  - 允许变化的元素只能位于该单元的组件内。
- 交付前：对最终 HEAD 完整采集一次，共 73 个状态 × 2 种视口，与 `2c69500` 的完整基线对比。
- 本批新增的状态：

| 状态 | 内容 |
| --- | --- |
| `ctx-hover`、`ctx-keyboard`、`ctx-submenu`、`ctx-danger-hover` | 右键菜单：悬停、方向键焦点、展开子菜单、悬停危险项 |
| `more-hover`、`more-keyboard` | 「更多」菜单：悬停、键盘焦点 |
| `card-menu-hover`、`card-menu-danger-hover`、`card-menu-keyboard` | 项目卡片菜单：悬停、悬停危险项、键盘焦点 |
| `toolbar-subject-menu`、`toolbar-subject-hover`、`toolbar-frame-menu` | 工具栏菜单 |
| `project-menu`、`project-menu-hover` | 画布项目菜单 |
| `studio-select-open`、`studio-select-hover` | 选择框弹层 |
| `video-params`、`video-params-hover`、`video-model` | 视频参数弹层与模型选择（会写入数据，用独立副本） |
| `image-size-panel`、`image-settings`、`reference-picker` | 图片「画幅与尺寸」、生成参数、参考图选择 |
| `node-navigator`、`node-navigator-hover` | 节点搜索与悬停结果行 |

- 遮罩：加载转圈（`.spin`）、`progress`、设置页的存储统计（`.storage-stats`）与路径（`.path-box`）。采集时隐藏 `<video>` 元素和插入光标。
- 夹具：沿用前几批的 `fixture-comfy-log-focus`、`fixture-composer-summary-focus`。本批新增的状态全部是真实界面，没有夹具。
- `node-navigator-hover` 是 P1 时新增的状态。它的「之前」截图在 `c58c730` 上拍摄：先用 `git stash` 暂存 P1 改动，构建后采集，再恢复改动。
