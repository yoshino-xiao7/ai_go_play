# 设计系统阶段 1 第一批：状态色与禁用态（2026-11-19）

本页是带日期的执行记录。规范见 [Design System](../docs/design-system/README.md) 与 [Token 参考](../docs/design-system/TOKENS.md)。

## 范围

批准范围仅包括两项：

- 接入危险、警告、信息和焦点这几个语义 Token；
- 让确实处于禁用状态的主按钮改用可读的中性色。

不涉及业务逻辑、键盘交互、提交动作或其他设计领域。

- 分支：`codex/design-system-phase0`，独立工作树，阶段 0 基线提交为 `98ebb0e`。只在本地提交，未推送，未合并。

## 验证方法

- 数据：隔离端口；冻结的黄金数据，含 5 个项目和合成素材（扁平插画、6 秒视频、两段音频）、剧本与 4 轨时间线。不接触生产素材库，不使用凭据。
- 状态：共 41 个，每个采集 1920×1080 与 1440×900 两种视口。会写入数据的状态（提交图像生成、新建视频草稿）各自使用一份全新的数据副本。
- 「之前」：用 `git archive` 导出阶段 0 基线 `98ebb0e`，独立安装依赖并构建后采集。它与工作树在同一提交上构建的结果，在全部 72 个共有状态上一致。
- 「之后」：在 `7277fdd` 上采集。
- 判定：
  - 计算样式指纹逐元素比较，变化必须全部属于本批目标（包括继承颜色的图标）；
  - 像素按通道取最大差值，超过 24 计为变化。
- 确定性：对同一构建采集两次，全部状态一致。
- 遮罩：加载转圈（`.spin`）、`progress`、设置页的磁盘剩余空间（`.storage-stats`）与资料库路径（`.path-box`）；`<video>` 元素在采集时隐藏。
- 夹具：
  - 创作区 `<summary>` 只在工作流或能力报错时出现；
  - ComfyUI 日志 `<pre>` 只在真实服务输出日志后出现。

  隔离环境中这两种情况都无法产生，因此把对应元素注入真实页面，由应用自己的 CSS 渲染。状态名以 `fixture-` 开头，元素带 `harness-fixture` 类名或注明「[fixture]」文字。

## 结果

- 改动前后对比（82 张截图）：40 张完全一致，42 张有变化。逐元素检查，**非预期的变化为 0**。
- 「移入回收站」文字和确认按钮的变化在每个通道上都不超过 23，所以按通道阈值统计为 0 个变化像素。它们的色相已经从粉色移向朱红，但亮度几乎不变。
- 新增状态各自采集两次，结果一致；`canvas-panels` 状态在一次运行中出现过 12 个像素的图片边缘栅格化差异，此时计算样式没有变化。
