# 语音与口型：从零安装

适用于 Windows x64、NVIDIA 显卡和本地 ComfyUI。语音使用 IndexTTS 2.5，口型使用 LatentSync 1.5。先按项目 [README](../README.md) 安装基础画布；本页补齐这两个功能的环境、模型、节点及验收。教学视频将在前置验收完成后制作。

## 1. 准备 ComfyUI 和模型

1. 没有 ComfyUI 时，按 [官方 Windows 便携版说明](https://docs.comfy.org/installation/comfyui_portable_windows) 下载 NVIDIA 版并解压。先启动确认能打开本地 ComfyUI 页面。安装器支持便携版的 `python_embeded`，或 ComfyUI 目录/父目录内的 `.venv`、`venv`；其他布局暂不自动识别。
2. 从夸克 `ai-go-play` 下载 `05-indextts`、`07-latentsync`。需要“文本引导情绪”时再下载 `06-indextts-emotion`。不需要下载图像和 H3 大模型来测试语音、口型。
3. 将各包里的 `models` 内容合并到同一个模型目录，例如 `C:\AI\models`。不要把 `05-indextts` 本身当作模型目录，也不要只拷贝最大的权重文件。配置、tokenizer、清单同样必需。

```text
C:\AI\models\
├─ tts\IndexTTS-2.5\
│  ├─ config.yaml
│  ├─ manju-models.json
│  ├─ ...                 # 05 包的全部文件
│  ├─ hf_cache\w2v-bert-2.0\...
│  └─ qwen0.6bemo4-merge\...  # 可选，06 包
├─ lipsync\LatentSync-1.5\
│  ├─ latentsync_unet.pt
│  ├─ whisper\tiny.pt
│  └─ vae\...
└─ detection\face_detection_yunet_2023mar.onnx
```

实际文件以 [models.json](models.json) 为准，安装器逐个核对 [SHA256](model-checksums.sha256)。语音基础包约 6.60 GiB，情绪包约 1.13 GiB，口型包约 5.11 GiB。运行环境、下载缓存另外占空间；建议运行环境所在盘预留至少 50 GiB，模型所在盘预留至少 15 GiB。

## 2. 双击安装

双击项目根目录的 **`install-local-ai.cmd`**，依次选择：

1. ComfyUI 文件夹（含 `main.py`）或它的 `ComfyUI_windows_portable` 父文件夹。
2. 合并后的模型文件夹（上例 `C:\AI\models`）。

等待窗口显示 `Completed`。第一次需要联网下载 GitHub 源码、Python、PyPI 依赖、CUDA 版 PyTorch 和 FFmpeg；PyTorch 单个下载约 3.2 GiB，速度取决于网络。此入口无需先安装 Git、Python 3.11、CUDA Toolkit 或编译器，也无需管理员权限；NVIDIA 驱动和可运行的 ComfyUI 需要事先准备。

安装器会自动：

- 在项目 `.manju/local-ai/` 创建专用 Python 3.11.18，分别创建语音与口型虚拟环境。
- 安装带哈希的固定依赖，使用 PyTorch 2.8.0 / CUDA 12.8；固定两套模型的上游源码版本，并校验下载压缩包。
- 准备私有 FFmpeg/FFprobe，供推理与本项目媒体导入使用。
- 校验所选模型内容，检查关键依赖、分词器、人脸检测和一次 CUDA 运算。
- 所选组件全部检查通过后，复制 Manju 节点并生成 `runtime.json`。已有同名节点会先备份到运行环境的 `backups/`。

下载失败后，修复网络并用相同选项重跑即可；已校验的下载和独立环境可复用。不会把第三方推理依赖装入画布或 ComfyUI 的 Python。运行期间不会自动重启 ComfyUI。

安装完成、ComfyUI 队列空闲后，手动重启 ComfyUI 和画布。在画布设置中连接自己的 ComfyUI 地址，然后到工作流页面刷新：应出现 **IndexTTS 2.5** 和 **LatentSync 1.5** 就绪状态。

## 3. 命令行安装、重检和实际生成验收

下面命令在项目根目录的 PowerShell 执行，路径替换成自己的。

```powershell
# 与双击完全相同；支持有空格、中文的目录。
.\install-local-ai.cmd -ComfyDir "C:\AI\ComfyUI_windows_portable" -ModelsDir "C:\AI\models"

# 只安装语音；不装情绪包。
.\install-local-ai.cmd -ComfyDir "C:\AI\ComfyUI_windows_portable" -ModelsDir "C:\AI\models" -Components speech -Emotion off

# 换盘存放运行环境；以后重检、修复应传同一 RuntimeRoot。
.\install-local-ai.cmd -ComfyDir "C:\AI\ComfyUI_windows_portable" -ModelsDir "C:\AI\models" -RuntimeRoot "E:\AI\manju-runtime"

# 校验模型并重新检查已安装环境，不重新注册节点。
.\install-local-ai.cmd -ComfyDir "C:\AI\ComfyUI_windows_portable" -ModelsDir "C:\AI\models" -CheckOnly

# 空闲 GPU 上安装并自动生成测试音频/视频（两套组件）。
.\install-local-ai.cmd -ComfyDir "C:\AI\ComfyUI_windows_portable" -ModelsDir "C:\AI\models" -SmokeTest
```

`-Emotion auto` 是默认值：找到情绪模型目录就完整校验它；目录不完整会报错，需补齐或显式 `-Emotion off`。`-Emotion required` 强制要求该包。

基础检查不等于真实模型推理成功。空闲 GPU 上再运行：

```powershell
.\.manju\local-ai\envs\speech\Scripts\python.exe -I scripts/local_ai/smoke_test.py

# 单独验证可选的文本情绪模型。
.\.manju\local-ai\envs\speech\Scripts\python.exe -I scripts/local_ai/smoke_test.py --components speech --emotion
```

脚本使用固定上游 LatentSync 源码中的公开示例素材，生成一句中文语音和一秒口型视频。每次使用新建的模型缓存目录，并禁止 Python 进程建立网络连接。输出及日志在 `.manju/local-ai/smoke/<本次编号>/`；`report.json` 记录音视频时长、流类型和文件位置。请播放输出检查声音、画面和嘴部效果。测试使用 GPU，先结束其他生成任务并释放占用显存的模型。

只装一个组件时，可用该组件的 `envs/<组件>/Scripts/python.exe` 启动脚本；加 `--components speech` 或 `--components lipsync`。仅语音安装没有示例素材时传 `--reference "C:\AI\test.wav"`（2–30 秒），口型可传 `--video "C:\AI\test.mp4"`。自定义运行目录需加 `--runtime-root "E:\AI\manju-runtime"`。

也可在安装命令中加 `-SmokeTest -ReferenceAudio "C:\AI\test.wav"`，口型示例视频可用 `-TestVideo` 指定。仅安装语音时需要提供自己的测试参考音频。

最后在画布上各提交一次配音和口型任务，检查任务完成、素材入库及预览。真实工作流还依赖 ComfyUI 的连接、输入素材和可用显存。

## 4. 故障排查与恢复

| 现象 | 处理 |
| --- | --- |
| `Missing model files` | 按报错相对路径检查合并后的模型目录；不要漏配套小文件。 |
| `Model SHA256 mismatch` | 重新下载报错文件；大小相同也可能内容不一致。 |
| GitHub / PyPI / PyTorch 下载失败 | 检查网络、代理和剩余空间，然后重跑；日志在运行目录 `logs/`，不要关闭哈希校验。 |
| `CUDA is unavailable` 或 CUDA 内核失败 | 检查 NVIDIA 驱动是否支持 CUDA 12.8，确认不是 AMD/Intel/CPU 环境。 |
| 推理显存不足 | 关闭其他占显存程序，清空 ComfyUI 空闲模型缓存，先用短片段测试。安装自检不保证所有分辨率和时长都能运行。 |
| 节点没有出现 | 重启 ComfyUI，确认选择的是正在运行的那份 ComfyUI；查看其启动日志中的节点导入错误。 |
| `Refusing to overwrite` / 源码被修改 | 安装器保护已有环境和源码；选择新的 `-RuntimeRoot` 重新安装，或先自行保存修改并恢复对应固定源码。 |
| 更换盘符或移动项目后不能使用 | 配置含绝对路径，使用新路径重新运行安装器；不要直接移动已创建的 Python 虚拟环境。 |

安装报告为运行目录 `installation.json` 与 `reports/`。如果需要恢复原节点，在 ComfyUI 退出后从 `backups/` 将对应文件复制回 `custom_nodes/comfyui_manju_speech` 或 `custom_nodes/comfyui_manju_lipsync`，再启动 ComfyUI。安装器不会改模型文件或其他自定义节点。

开发验收可用 `-StageOnly`：环境照常安装和检查，节点先写入运行目录 `staged-bridges/`，不注册到现有 ComfyUI。这个选项不会让现有画布自动切到测试环境。

## 版本依据与范围

2026 年 11 月 13 日已在 Windows 11、RTX 5060 Ti 16 GB 上完成同机隔离验收：从空目录安装两套环境、重复安装、`-CheckOnly` 重检均通过，32/32 个语音/情绪/口型文件通过 SHA256。空缓存并封锁 Python 网络连接后，分别生成约 2.64 秒中文语音、约 2.64 秒文本情绪语音，以及 1080×1920、25 帧、带音轨的一秒口型视频。隔离的 ComfyUI 实例也已完成配音和口型任务并保存输出；ComfyUI 本身使用现有便携版，此次没有重装系统或换电脑。

固定下载信息在 [sources.json](../scripts/local_ai/sources.json)，直接依赖在 [speech.in](../scripts/local_ai/speech.in) / [lipsync.in](../scripts/local_ai/lipsync.in)，解析后的全部运行依赖及哈希在同目录 `.lock` 文件。选择 [PyTorch 官方版本组合](https://pytorch.org/get-started/previous-versions/) 中的 2.8.0 / torchvision 0.23.0 / torchaudio 2.8.0、CUDA 12.8；Python 由 [uv](https://docs.astral.sh/uv/getting-started/installation/) 管理；FFmpeg 来自 [Gyan Windows builds](https://www.gyan.dev/ffmpeg/builds/)。这些第三方组件和模型分别遵循其原许可证。

此入口目前针对 Windows x64 + NVIDIA；不是 macOS、Linux、AMD 或纯 CPU 的通用安装器。另一台真实电脑和其他显卡的兼容性仍需单独验收。
