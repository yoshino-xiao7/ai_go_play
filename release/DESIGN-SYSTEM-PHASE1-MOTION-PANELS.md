# 设计系统阶段 1：遗留模板交互与侧面板动画（2026-11-20）

本页是带日期的执行记录。问题见 [样式债务](../docs/design-system/STYLE-DEBT.md) D10、D11，规则见 [Token 参考](../docs/design-system/TOKENS.md)「动效」。

## 范围

批准范围是迁移方案第 8 项：

- 遗留模板交互的去留（D10）；
- 画布素材面板与检查器的开关动画（D11）。

不修改工作区挂载模式、配色、层级、业务逻辑和其他面板，不进入第 9 项。分支 `codex/design-system-phase0`，起点 `cf607e4`。只在本地提交，未推送，未合并。

## 实测（`cf607e4`，Edge，1440×900 与 1920×1080，正常与减少动态效果）

| 效果 | 作用范围 | 实测 | 判定 |
| --- | --- | --- | --- |
| `.btn` 悬停上浮 −1px | 首页与对话框按钮、安装向导按钮 | 悬停时背景和描边已经变化（`#242022` → `#2d282a`，140ms） | 装饰，删除 |
| `.btn` 按压 `translateY(1px) scale(.985)` | 同上 | 按下时生效；减少动态时为 none | 按压线索，保留 |
| `.btn` 颜色过渡 | 同上 | 140ms 进入、200ms 退出 | 悬停反馈，保留 |
| `.card` 悬停上浮 −2px、边框变亮、深阴影 | 项目卡片、资产卡片 | 指针停在标题区也会触发，而卡片整体并不能点击 | 装饰且误导，删除；封面的「打开」箭头、项目名颜色、资产卡片显出的操作按钮仍是悬停线索 |
| 封面图 1.03 放大（600ms） | 项目封面、资产封面 | 只是放大 | 装饰，删除 |
| `.m-zoom { overflow: clip }` | 项目封面 | `.project-cover` 有 11px 圆角，但没有自己的 overflow | 起裁切作用，保留 |
| 焦点环渐入动画 `m-focus`（200ms，从透明开始） | 所有可聚焦元素 | 焦点环要 200ms 才完全出现；减少动态的覆盖规则特异性较低、没有生效，这时动画仍会运行 | 装饰且违背减少动态效果，删除；焦点环本身（2px、偏移 3px）不变，立即出现 |
| 段落内链接下划线展开 | 没有类名的段落链接（安装向导、设置） | 是这类链接唯一的悬停线索 | 保留；减少动态时即时完成（包括悬停） |
| 素材面板 / 检查器开关 | 画布左右两侧 | 声明了 0.22s 的 transform 和 0.18s 的 opacity 过渡，但开关靠 `display:none`，400ms 内逐帧采样只有 1 个状态 | 修正为真正生效的过渡（D11） |

## 变更

| 提交 | 单元 | 内容 |
| --- | --- | --- |
| `6be7978` | M1 遗留动效 | `motion.css`：删除按钮悬停上浮、卡片上浮 / 边框 / 阴影、封面放大、焦点环动画，以及不再使用的 `--m-image` 和 `--m-lift`；减少动态时按压无位移、链接下划线即时完成 |
| `5c07cd6` | P1 侧面板 | `canvas.css`：`display` 使用离散过渡（`allow-discrete`），关闭时可以淡出；`@starting-style` 提供打开时的起点（透明度 0，偏移 12px）；减少动态时不使用过渡。`Canvas.tsx`：关闭的面板同时设为 `inert`。挂载方式和开关逻辑不变 |

## 验证

- 每批都执行了：
  - `npm run build`（含 `tsc -b`）；
  - `node --test tests/governance.test.cjs` 14/14；
  - 动效探针 `motion_probe.py`：两种视口 × 正常 / 减少动态效果，全部为真实交互，包括悬停、按下、Tab、工具栏开关点击、对聚焦的开关按 Enter；
  - 受影响状态与相邻对照的计算样式和像素比较。
- 过程帧：交互后把页面上所有正在运行的动画暂停在第 80ms 截图，前后两版是同一时刻。修改前没有动效，所以「之前」帧就是终态。
- 交付前：对最终 HEAD 完整采集 101 个状态 × 2 种视口，与复用的 202 张基线比较（`20bf46f..cf607e4` 只改了文档，`dist` 533/533 哈希一致）。

结果：

| 项目 | 之前 | 之后 |
| --- | --- | --- |
| 按钮悬停 | 上浮 −1px，加上颜色变化 | 只有颜色变化；按压保留（减少动态时无位移） |
| 卡片悬停 | 上浮、边框、阴影、封面放大 | 卡片不动；「打开」箭头仍出现 |
| 焦点环 | 200ms 渐入（减少动态时也会运行） | 立即出现，样式不变 |
| 面板打开（正常） | 瞬时，1 个状态 | 约 220–264ms，13–14 个过程状态，从透明度 0、偏移 12px 开始 |
| 面板关闭（正常） | 瞬时 | 约 255–260ms 淡出 |
| 面板（减少动态） | 瞬时 | 瞬时，终态相同 |
| 关闭中与关闭后 | 点不到、不可聚焦、不在 Tab 顺序中 | 相同（因为 `inert`，淡出过程中也成立） |
| 快速切换（5 次，间隔 40ms）、Enter 开关 | 终态正确 | 终态正确 |

最终完整采集：

- 202 张截图，0 张失败，非预期元素变化 0，181 张像素一致。
- 有像素变化的都是悬停态：卡片菜单、卡片、`.btn` 按钮，包括「清除搜索」和禁用的「导入项目」夹具。
- 只有计算样式变化（131 个状态）的，是关闭面板的静止透明度，这些面板处于 `display:none`，看不见。
- `1440-reference-picker` 的缩略图在那一次采集中尚未加载完成。在同一构建上复拍，与基线 0 像素差异，属于采集时序问题。

## 未覆盖与限制

- 窄视口没有采集；面板相关的改动不涉及媒体查询。
- 面板在约 0.25 秒的过渡中带有 `transform`，这段时间内面板里的固定定位后代会以面板为参照。目前面板内的弹出层都通过 portal 挂到 `body`，不受影响。
- 资产卡片的悬停终态只能由完整采集中的资产页覆盖，资产页里没有悬停状态。
- 只在 Windows 的无头 Edge 中验证。
