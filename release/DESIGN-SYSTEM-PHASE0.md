## 验证方法

- 隔离实例：独立端口，每次运行都从冻结的黄金数据复制一份新数据（5 个项目，合成素材，含剧本与 4 轨时间线），不接触生产素材库，不使用凭据。
- 采集 27 个界面状态，每个状态采集两种视口（1920×1080、1440×900）：项目首页、卡片悬停、卡片菜单、新建弹窗、资产库、回收站、设置、工作流、关于、安装向导三步、画布（全局视图、工具栏悬停、缩放按钮悬停、双侧面板、选中图片、选中视频、右键菜单、选中连线、更多菜单）、剧本（阅读、编辑）、时间线、分镜成片、口型同步、ComfyUI、任务。
- 比较两项内容：每个元素约 45 项计算样式及位置尺寸；像素差异以任一通道超过 24 计为变化。
- 涉及媒体查询的单元，追加 1200×800、840×700 视口；涉及悬停规则的单元，追加对应的悬停状态。
- 已知噪声：设置页的磁盘剩余空间和资料库路径，采集时遮罩；`<video>` 元素在采集时隐藏，以排除帧时间差异。
- 基线一致性：工作树重新构建出的 22 个产物文件，与原视觉基线所用的构建逐字节相同。可比较的状态（安装向导欢迎页与引擎页、关于页，两种视口）与人工复核时的 138 张截图逐像素一致。重复运行同一构建，除磁盘剩余空间外完全一致。

**更正（2026-11-19，阶段 1 期间发现）**：阶段 0 实际使用的像素比较，是先把差值图转成灰度再判断是否超过 24，并不是上文所写的「任一通道超过 24」。这种做法会漏掉只改变色相的变化。阶段 1 改用按通道取最大值的比较，并对阶段 0 的全部比较重新检查：u1 至 u5、final、窄视口和悬停各组均一致，唯一的差异是 u1 设置页缺少路径遮罩，这一点已由 u1s 补测覆盖。此外，阶段 0 的每个单元计算样式指纹都完全一致，这项检查本身就足以支持「界面无变化」的结论。

## 未覆盖的范围

- 状态集合中没有的浮层（视频和图片查看器、下拉选择弹层、自动编排遮罩、选择横幅、参考素材预览）没有渲染比较。对这些浮层，`z-index` 改为 Token 后数值相同是由替换方式保证的：每个 Token 都定义为它所替换的那个数值。
- 没有 ComfyUI 与模型，生成中、生成成功、候选对比这几种状态无法渲染；阶段 0 也没有修改相关样式。
- 只在 Windows、Microsoft Edge 的无头模式下验证，没有在其他浏览器或系统上验证。
- 回归工具与黄金数据保存在仓库外；纳入仓库的计划见 [迁移方案](../docs/design-system/MIGRATION.md)。
