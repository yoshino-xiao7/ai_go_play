## 层叠关系（实测）

| 层 | 值：之前 → 之后 | 挂载位置 |
| --- | --- | --- |
| 提示 `.toast` | 200 → 5100 | `#root` |
| 图片查看器遮罩 | 5000（不变） | `<body>` portal |
| 视频查看器 | 1500（不变） | `<body>` portal |
| 自动编排遮罩 `.canvas-run-shade` | 1800 → 1850 | `#root` |
| 右键菜单、视频参数弹层 | 1800（不变） | `<body>` portal |
| 选取横幅 | 1800（不变） | `#root` |

所有层都是 `position: fixed`。实测 `#root` 下各层的祖先链上没有建立层叠上下文的元素，所以全部在根层叠上下文中比较：z-index 大的在上；值相同时，DOM 中靠后的在上（portal 总是更靠后）。

## 未覆盖与限制

- 自动编排面板没有限制焦点，Esc 也不能关闭它；选取模式进行中时，第一次 Esc 会取消被遮住的选取。这些都属于交互，按范围不修改，记录在 D6。
- 视频查看器（1500）低于参考图选择、右键菜单等层。查看器打开时这些层都会关闭，没有找到可复现的冲突，因此不改。
- 提示固定在底部中央，现在会在所有层之上短暂显示；它可以点穿，不会拦截点击。
- 窄视口不在本批要求之内，没有采集。
- 只在 Windows 的无头 Edge 中验证。
