# 安装依赖镜像

启动器读取网络出口所在国家或地区来选择首选源。查询超时后使用 Windows 地区设置。用户可在失败页切换优先顺序，也可以在运行启动命令前设置 `MANJU_DOWNLOAD_SOURCE=china` 或 `MANJU_DOWNLOAD_SOURCE=overseas`。可用文件通过校验后放入项目的本机缓存。

| 下载项 | 海外来源 | 中国大陆候选 |
| --- | --- | --- |
| uv Windows x64 | GitHub 官方 ZIP | 阿里云 PyPI 中同版本的 Astral 官方 wheel |
| Python 3.12、3.11 | Astral Python 独立构建 | npmmirror |
| Node.js、npm 依赖 | Node.js 官方发行版和 npm registry | npmmirror |
| 工作台、语音、口型和 ComfyUI 节点的 Python 依赖 | PyPI | 阿里云 PyPI、项目自建镜像 |
| 固定 CUDA PyTorch wheel | PyTorch | 阿里云 PyTorch wheels |
| FFmpeg、FFprobe、ComfyUI、7-Zip、Python 头文件和固定节点源码 | 各组件官方固定版本 | 项目自建镜像 |

大陆优先时，下载器尝试适用的国内公共源、项目镜像、海外源。海外优先时，先尝试海外源，其次尝试适用的国内公共源和项目镜像。启动时只读取 Cloudflare 响应中的地区代码，并且不把它写进配置或日志。

## 构建项目镜像

使用 Python 3.12+ 执行。输出应写到 Git 工作区之外或被忽略的目录。模型权重通过单独的模型下载流程分发。

```powershell
python scripts/build_download_mirror.py D:/mirror/ai-go-play --plan
python scripts/build_download_mirror.py D:/mirror/ai-go-play --reuse .manju/bootstrap/downloads --wheelhouse D:/mirror/windows-wheels
```

导出器按发布配置校验程序 ZIP、ComfyUI、节点、语音和口型固定源码、独立 Python、CUDA wheel 和 npm 锁文件中的 tarball。可以使用安装器的已下载缓存避免重新下载。 `--wheelhouse` 将准备好的 Windows Python wheel 转成静态 Simple Index。按实际支持的 CPython 3.11、3.12、ComfyUI Python 版本和节点依赖填充与验收该目录，才能离线于公共 PyPI 源安装对应组件。

国内项目镜像部署在上海 OSS 的 `ai-go-play-runtime-cn` Bucket，使用 `runtime/v1/` 作为长期保留路径。镜像根地址写在 `release/download-sources.json` 的 `project_mirror`，可通过 `MANJU_PROJECT_MIRROR` 临时覆盖。托管文件见 [镜像清单](https://aigo.suzuki.ink/runtime/v1/mirror-index.json)。

维护镜像时保留 `artifacts/`、`npm/`、`pypi/` 和 `python-build-standalone/` 路径。私有 OSS 由 ESA 签名回源，发布 Simple Index 时将 `index.html` 同时写到对应的尾斜杠对象键，供 pip 和 uv 直接读取。先上传依赖文件，再更新索引。发布前用 HTTPS Range 请求抽查大文件的分段响应和内容。

正式对外开放前，核对第三方组件的分发许可证和对应源码要求，尤其是 FFmpeg 与便携版内的第三方依赖。开启公开访问时仅发布镜像目录中的审定文件。固定版本的 SHA-256、Python wheel 锁文件哈希和 npm integrity 继续生效。
